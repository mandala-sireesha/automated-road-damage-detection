# Automated Road Damage Detection

A Django web application that detects and classifies road damage using a deep learning model.

## Tech Stack
Python, Django, TensorFlow/Keras, HTML, CSS

## How to Run
1. Clone the repository
2. Install dependencies: pip install django tensorflow pillow
3. Download the model file (road_classification_model.h5) from the link below and keep it in the project folder
4. Run: python manage.py runserver
5. Open http://127.0.0.1:8000
